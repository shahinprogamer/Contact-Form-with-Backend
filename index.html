How it works

Four steps from click to saved

1

Browser check

Instant feedback on name, email and message length.

2

POST request

JSON is sent to the REST endpoint with fetch.

3

Server check

The server validates again and rejects bad data with 422.

4

Saved

The message is stored with an id and timestamp, then confirmed with 201.
